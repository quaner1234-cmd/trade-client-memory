汇报规则(SKILL.md Phase 5):

- 每个客户最多两三行;按 urgent → action → waiting → unconfirmed 排序。
- 明确区分「业务员需要行动」「等待客户」「信息待核实」。
- 首次整理展示全部客户;增量更新只展示有变化的客户,其余让用户看 `客户概览.md`。
- 客户多时只展示最优先者,完整列表在概览文件里。
- 不输出运行日志、技术测试数据;用户问技术细节时再提供。
