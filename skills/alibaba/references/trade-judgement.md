# 外贸判断规则（复用 Email Skill 的判定口径）

整理阿里询盘时，这些判断容易出错。**不确定就写「待确认」，不要猜。**

## 平台数据 ≠ 事实

| 平台显示 | 正确写法 | 错误写法 |
| --- | --- | --- |
| Quantity: 500 pieces / 500 unidad | 「平台数量字段显示 500，未确认」 | 「客户要 500 件」 |
| 通知标题里带国家名 | 「平台标注 XX（未核实）」 | 「客户来自 XX」 |
| 聊天里的图片 | 「客户发了图片（链接见附件）」 | 据此认定品牌/公司/国家 |
| 买家发名片/卡片 | 「收到名片，内容待核实」 | 直接填入公司名 |

**平台数量字段常常是默认值或询盘模板带的**，不等同于采购意向或订单。

## 阶段判断

| 情况 | 阶段 | 说明 |
| --- | --- | --- |
| 只有买家第一句问话 | 初始询盘 | 别跳到报价 |
| 我方已回复但客户未回 | 初始询盘 / 等待客户回复 | 「我方已发」≠「客户已收到/已回」 |
| 客户明确要样品 | 样品确认 | 仍未报价就不算报价阶段 |
| 已发正式报价单 | 报价阶段 | 需要有报价动作，口述价格不算 |
| 客户在催、有临期事项 | urgent | 提高优先级，让业务员马上处理 |

## 我方 vs 客户

- 「我方已发消息」说明**我方行动了**，不代表客户知道结论。
- 「我方最后一条是自动跟进（automatic follow-up）」**不算人工跟进**，进展里要标「暂无人工回复」。
- 系统消息（"The buyer has been assigned to you" / "transferred"）是平台流转，**不是客户说的话**。

## 客户身份

- 免费邮箱 + 无公司佐证 → 标「待 / 未确认」，不要并入已有同名客户。
- 库里出现同名不同会话 → 一律落 `_待确认/`，由人工判断，**脚本和 Agent 都不猜**。
- 同一客户换会话号来问 → 归入同一客户文件夹，不新建。

## 语言

俄语、西班牙语、阿拉伯语等多语消息：保留原文，给参考译文并注明「翻译仅供参考」。不要用转述替代原文，也不要因为看不懂就判定为无效询盘。
